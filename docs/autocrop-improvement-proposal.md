# 名刺自動切り取り改善 — 調査メモと提案（段階2）

**作成日:** 2026-11-11  
**対象コード:** `lib/meishi-crop.js`、`app.js`（`warpQuadToRect` / `autoCropMeishi` / `detectCardCorners`）  
**前提:** 本ドキュメントはコードレビューに基づく**仮説**です。実機（Pixel + Chrome PWA）での計測・検証は**未実施**です。

---

## 1. ユーザー症状との対応関係

| 症状 | コード上の関連（仮説） |
|------|------------------------|
| 端が正しく取れない | 四隅検出が名刺矩形ではなく背景／影／机の境界を拾っている可能性 |
| 自動補正後に斜めになる | 四隅の順序・辺の対応ミス、または検出点が平行四辁形として不正 → 射影変換で台形のまま出力 |
| 元に戻せず再撮影のみ | **段階1（20261111a）で undo / 元写真復帰を実装済み**（本提案書は検出精度側） |

---

## 2. 現行パイプラインの整理

1. 撮影 → `resizeBase64`（長辺 2000px 程度）→ 必要なら `ensureLandscapeBase64`
2. **自動で真四角** → `MeishiCrop.detectCardCorners`（縮小 Sobel + 凸包 + 最大四角形探索）
3. 検出四隅に **outset（約 2.2% 外側拡張）** → `warpQuadToRect` で正面矩形へ
4. 失敗時は手動 **4点で切る**（初期枠 3% インセット or 検出結果）

---

## 3. 失敗要因の仮説（検証可能な形）

### H1: 縮小サンプリングで四隅が粗い
- 検出は最大幅 420px 前後にダウンサンプル（`detectCardCornersFromData`）。
- **検証案:** ログに検出四隅と原寸比較、手動4点との差分ピクセル数を端末で記録。

### H2: 凸包＋組み合わせ探索が「机・背景」の大きい四角を選ぶ
- 最大面積の四角を採用するため、名刺より外側のコントラスト縁が勝ちやすい。
- **検証案:** 候補四角形ごとにアスペクト比（名刺 91:55 ≈ 1.65）フィルタをかけたときの成功率比較。

### H3: 射影変換の頂点順序ミス
- `orderQuadPoints` は tl/tr/br/bl 推定だが、強い台形で辺が入れ替わると「斜めに見える」出力になる。
- **検証案:** 補正後画像に Hough／水平エッジエネルギーを測り、水平度スコアが閾値未満なら「低信頼」とする。

### H4: 自動補正後に `skipAutoLandscape` が true となり、後段の向き補正がスキップされる
- 意図した挙動だが、誤検出と組み合わさると「直せない斜め」に見える。
- **検証案:** 段階1の「元の写真に戻す」で手動フローへ誘導（実装済み）。

### H5: 撮影時の遠近・反光でエッジが切れる
- 白い名刺・木目机では Sobel 閾値が不安定。
- **検証案:** 失敗サンプル画像で閾値 `eThr` / `dThr` をスイープ（オフライン再現テスト）。

### H6: 透視補正の出力解像度が辺長平均から決まり、アスペクトが崩れる
- `warpQuadToRect` の outW/outH は検出辺の平均から推定。
- **検証案:** 固定名刺アスペクト（例 1.65:1）を出力にクランプした A/B 比較。

## 5. 推奨ロードマップ（コード変更を小さく段階投入）

### フェーズ A（短期・PWA のみ）
1. **信頼度スコア**（アスペクト比・四角形面積比・補正後水平度）を `autoCropMeishi` 後に算出。
2. 閾値未満 → **自動適用せず**「4点で切る」を開き、検出点を初期値として表示（案 B + F + E の一部）。
3. **ガイド枠オーバーレイ**（名刺比率 1.65:1）をビデオ上に常時表示（案 A）。

### フェーズ B（中期）
4. 自動検出成功時も **四隅プレビュー確認画面**（適用前に確認、ドラッグ調整）（案 E）。
5. `lib/meishi-crop.js` に名刺アスペクトペナルティ・最大面積ではなくスコア最大化へ変更（案 B）。

### フェーズ C（必要なら）
6. OpenCV.js または jscanify を **オプション遅延ロード**（設定で有効化、オフライン初回は待ち）（案 C/D）。
7. Gemini 四隅はコストと失敗モードのため**最後の候補**（案 G）。
